# スパイクの結果：Swift での Unigram トークナイザ

意味の層（spec-local-ai.md）を macOS 版で Swift だけで実装できるかを確かめた。
判定は **GO**。

埋め込みそのものは Core ML を呼ぶだけで、Swift の母国語である。
難所はトークナイザだけだった。**食い違っても例外は出ず、黙って違うベクトルが出る**ので、
参照実装との照合以外に守る手立てが無い。そこを先に潰した。

実蔵書の本文でも照合したが、書籍の題名・著者・本文はここに書かない。

## 判定

| | |
| --- | --- |
| 実装 | 211 行（Unigram + Metaspace + byte fallback + 特殊トークン + `<s>…</s>`） |
| 照合 | **生成した端 5,028 件・実書籍の本文 887 断片、合わせて約 27 万トークンで食い違い 0** |
| 参照 | Rust の `tokenizers` crate（`Tokenizer::from_file` → `encode`）|

Ruri v3 の `tokenizer.json` は **30m / 130m / 310m で同一**（SHA-256 一致）。
Unigram、語彙 102,400、`unk_id` 0、byte fallback あり、normalizer なし、
pre_tokenizer は Metaspace（`▁`、`prepend_scheme=never`、`split=false`）、
post_processor は `<s> … </s>`。**モデルの大きさを替えてもトークナイザは替わらない。**

## 黙って間違う罠が 3 つあった

いずれも例外を出さず、照合しなければ気付けないものだった。

### 1. Swift の `String` は正準等価で比べる

語彙を `[String: …]` の辞書に入れると、「が」（1 符号位置）と「か」＋濁点（2 符号位置）が
**同じ鍵になる**。この語彙には実際に**そうした対が 15 組**あり、片方が黙って消える。

同じ理由で `replacingOccurrences(of: " ", with: "▁")` も当たらない。
空白＋結合文字は 1 つの `Character` になるためである。
**照合 5,028 件のうち 860 件がこれで食い違った**（`▁` になるべきところが byte fallback の `<0x20>` になる）。

→ 語彙の鍵・特殊トークンの切り分け・空白の置き換えを、すべて **UTF-8 のバイト列**で行う。

### 2. 点の足し込みは Double でないと分け方が変わる

語彙の点は f32 で書かれているが、参照実装は **f64 で積む**。
同じ点になる分け方が並んだとき（目次の点線のような同じ字の連なり）、
f32 の丸めで順位が入れ替わり、分け方が変わる。

生成した端では出ず、**実書籍の本文で 887 断片中 56 件**として出た。
端の生成だけでは足りない、という例になった。

### 3. 同点のときにどちらを採るか

参照実装は「先に入った節点」を採り、それは開始位置の小さい方（＝長い語彙）になる。
バイト位置を昇順に進め、`>` （等号を含まない）で更新すれば同じ結果になる。

## 速さ

| | |
| --- | --- |
| Swift | **8.9 µs/トークン**（1 単位 512 トークンで 4.6 ms） |
| Rust（参照） | 1.6 µs/トークン |
| 語彙の読み込み | 0.13 秒（1 度きり） |

Rust の 5.5 倍かかるが、**埋め込みが ANE で 22 ms/単位なので、トークナイザは全体の 2 割**。
索引を作る速さを決めるのは ANE の側である。必要になれば trie を持ち込む余地はあるが、
いまは素朴な走査（1 バイトずつ、語彙の最長までの窓）で足りる。

## 設計への含み

- **macOS 版は Swift だけで完結できる。** 埋め込みのために Rust の実行物を
  アプリに同梱しなくてよい。macOS 版は自己完結という本体の構成（spec.md 第 13.1 節）を崩さない
- **Core AI / Foundation Models も Swift からしか呼べない。** Level 3（生成系）へ進むなら
  AI 層は結局 Swift になる。埋め込みだけ別プロセスに出すと層が二つの形に割れる
- **kohagi の役割は残る。** 変換器（`coreml-convert`）、照合の参照（オラクル）、
  そして Windows 版（Tauri）に意味の層を入れるときの実装。
  「同じ契約を各実装が独立に満たし、治具で突き合わせる」という本体の形に、埋め込みも載る
- モデルは公開済みの Core ML 変換物をそのまま使える。変換は kohagi 側に残す
